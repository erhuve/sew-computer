## Numerical continuation review · 2026-09-23

This continuation found defects beyond the earlier review scopes. Historical test counts below remain historical; neither those results nor the fixes here establish accepted cuff construction, full-shirt assembly or deployment readiness.

### Contact locality and native parameter identity

The experimental rest-filtered v1 implementation selected one reduced activation/minimum scale from the smallest within-panel rest separation in the entire input. Adding a distant, stationary refined panel could therefore erase the original panel's contact response. This violates locality even when the broad phase supplies a complete candidate set; the rest-filtering partition itself does not drop candidates. Historical v1 refined-mesh controls must not be promoted to model acceptance.

`experimental-rest-filtered-contact-v2` assigns each filtered primitive pair its own fixed rest-distance-derived scale: activation is one quarter of that pair's rest separation, and minimum separation is the smaller of full thickness and that activation. Only identical parameter values share an evaluation bucket. Inter-panel candidates retain full thickness; rest filtering discards no additional nonincident candidate. The profile records membership and parameter hashes, ranges, bucket counts and the rule. This is an explicit model revision, not an equivalent replay of v1.

Independent regressions verify unchanged original energy, forces and curvature when unrelated distant panels are added or refined. A separate 121-candidate sum reproduces grouped energy, forces and Hessians across changing closest-feature reductions. Review also found that mutable native barrier/CCD objects could change the effective model while its profile stayed fixed. Public evaluations now reject such parameter drift, including cached evaluations. The initial **21 rest-filtered tests passed on macOS ARM**; the subsequent Linux run exposed the separate broad-phase defect below.

Closest-feature transitions retain continuous forces and piecewise curvature; there is no unique ordinary Hessian at a transition. Locality does not prove refinement-convergent quadrature, globally uniform sheet thickness, material calibration or acceptable layer order. The regenerated coarse cuff has **zero filtered pairs**, so this locality fix does not itself explain or resolve its fold-tracking failure.

### Every triangle's physical path

Nonincident contact certificates can pass a motion whose individual triangles collapse between valid endpoints. A two-triangle counterexample rotates each face by 180 degrees under affine interpolation: both endpoint meshes and normal-offset seam residuals are valid, but both triangles collapse at the midpoint. An isolated face need not belong to a guarded hinge.

`solver_triangle_sweep.py` checks every source face on both optimizer segments and proposed physical steps. A bounded, scale-normalized Bernstein calculation fails closed on an unresolved path. Cloth starts from the previous state; the unguarded `lsmr` route rejects cloth triangles. An independent exact-rational replay calculation proves nonzero triangle area throughout each saved affine interval using the exact binary64 endpoint values. It is loaded from the current verifier's captured bytes before historical numerical snapshots enter the import path; its digest is recorded separately.

The **12 focused triangle tests pass**, including off-grid tangencies, mixed safe/collapsing faces, scales from `2^-500` to `2^500`, malformed indices, exhausted budgets and independent-oracle attacks. The runtime numerical guard is not directed interval arithmetic. The exact verifier proves nonzero area, not a physical minimum area, bounded strain, contact clearance or global layer order. Historical saved paths have not acquired this proof merely because the replay tool was updated.

### Portable fold-energy differences

On Apple ARM, `numpy.longdouble` has binary64 precision. Subtracting independently rounded angles lost significant digits in tiny fold-energy updates; two existing tests failed without any changed tolerance. The repair propagates small coordinate increments through edge/normal rotations and evaluates the corresponding barrier difference. Tests now use an independent 65-digit Decimal geometry/angle oracle instead of rounding through the same platform angle calculation.

Adversarial review caught a first-version regression under extreme uniform contraction. The final code restricts incremental evaluation to well-conditioned small changes and uses independently validated endpoint geometry for large changes. **36 distinct focused fold tests pass**, including the reviewer's exact binary rescaling, tiny motion at multiple scales, sign/activation crossings, mixed batches and rejection cases. Simultaneous huge rescaling and an extremely small rotation still has endpoint-rounding limits; arbitrary-transform relative accuracy is not claimed. None of these arithmetic checks establishes material correctness.

## Source and contact boundaries

Allowance geometry is explicitly derived from `draft.cutLine`, not relabeled as seam-line geometry. Per-vertex weights reconstruct cut-contour coordinates. Stitch paths reconstruct the original seam-edge polylines; per-triangle segment splitting permits future weighted constraints without substituting nearest vertices. The module retains `solverReady: false`: binding wraps, turning, folds, material bulk and weighted-constraint execution remain absent.

The contact filters use immutable rest-edge path distance, not current spatial proximity. Triangle and edge validation prohibits crossing physical instance IDs. This prevents coincident shell/facing pieces from becoming each other's excluded neighbors, and disconnected patches cannot be joined merely because their rest coordinates coincide. Newton's installed SolverVBD interface accepts the vertex-to-triangle and edge-to-edge exclusion maps used by the harness.

The original v1 endpoint-neighborhood method was rejected because a nearby endpoint exempted an entire long primitive, including distant cloth. Historical v1 numerical outputs must not be treated as acceptance. The final `same-instance-whole-primitive-rest-geodesic-v2` profile requires all triangle corners to be local to the query vertex and every cross-edge endpoint pair to be local before exclusion. Long source edges are also conservatively retained. Close primitive interiors can still remain candidates when endpoints are distant. A stationary-piece improvement therefore cannot certify safe self-contact during folding. Full dynamic contact and independent collision-oracle gates remain required.

No blocker was found in these narrowly labeled source-embedding and research-filter paths by the checks above. This is not release approval, full-shirt assembly acceptance, or an assertion that the garment simulation succeeds.
