# Pattern-derived 3D foundation: adversarial implementation review

**2026-09-16 · Independent review · Offline foundation and asynchronous interpretation only**

## Reviewed scope

The dedicated [3D engine plan](../plans/pattern-derived-3d-engine.md) remains active. This review covers `services/engine/assembly.py`, `meshing.py`, `simulation_validation.py`, `inspection_gltf.py`, their tests, the independently authored physical-inventory fixture, and the asynchronous interpretation queue/API/browser changes.

The engine foundation inventories physical fabric roles, tessellates actual sampled 2D seam-line geometry, records source correspondence and named boundary samples, expands mirrored physical instances, and writes a self-contained GLB containing a rigid flat arrangement. Classification is **placement inspection**. It does not assemble or simulate a garment. Seam allowances and their bulk are omitted. Interfacing, turning, bindings, gathers, localized closures and contact remain explicit capability gaps.

This is not E0 solver approval, complete E1/E2 acceptance, E3 worker validation, viewport approval, drape validation, physical-fit evidence or deployment authorization. Solver-candidate work requires its own evidence. The Python helpers are an offline trusted pipeline, not an authenticated production worker or an untrusted GLB ingestion boundary.

## Independent source audit

The full component shirt has **18 source templates, 24 fabric instances and six additional interfacing roles**. Quantity-two templates represent shell/facing layers, not mirrored pairs. Each already named left/right torso or sleeve is cut once. Curved tails are integral back-panel contours, not separate fabric pieces.

The fixture `packages/test-fixtures/assembly-expected.json` was authored independently from the source construction instructions. It contains exact full-shirt roles and seven variant expectations, plus obligations for multi-way attachments, self-seams, gathers, free edges, closures and assembly ordering. It is not generated by the implementation under test.

Required unresolved semantics include the four-layer torso/placket/frill junction, separate sleeve-opening bindings, unsewn cuff extensions, shell/facing perimeter construction, and the collar stand's layered neckline attachment. An inventory manifest cannot establish those operations merely by copying template stitch pairs.

Additional independent boundary mutations removing a sample, reversing sample order and replacing its vertex were rejected. Extremely thin and near-collinear source polygons failed within bounded mesh checks rather than producing an accepted mesh. Union/area, winding, source reconstruction and element-use checks reject duplicate, missing, inverted and unused geometry.

Physical instance expansion preserves source vertex order, reflects the declared side exactly once and reverses winding for that reflection. The GLB conversion applies millimetres-to-metres and a further Y reflection with corresponding winding reversal. Source template and physical instance identities remain in GLB metadata. No external buffer or texture URI is generated. Following review, accessor extrema now derive from float32-roundtripped coordinates matching the packed buffer.

The offline `scripts/inspect-pattern-3d.py` entrypoint reads bounded input files, imposes CPU/address-space/file-size limits, and writes to a newly created mode-0700 output directory. Inspection found no credential forwarding, networking or subprocess launch. Those controls do not establish a security sandbox, authenticated publication, process-tree isolation or an atomic production installation protocol. The CLI's partial output on an interrupted write is not a published application artifact.

## Remaining gates

Source-derived topology is necessary but does not prove garment assembly. Supported solver installation, benchmark profiles, explicit seam/turn/fold/contact semantics, material behavior and full-shirt numerical validation remain mandatory. The current rest-fidelity profile explicitly declines solver-quality acceptance; its tolerances are digital geometry checks, not sewing tolerances.

Before accepting production artifacts, independently validate the final expanded geometry and display derivative, capture immutable revision/runtime/profile identity, enforce worker and artifact budgets before publication, and execute the planned authorization/disclosure matrix. Current mirroring and GLB tests do not constitute a browser compatibility or privacy release test.

The database migration advances to version 4. Earlier application binaries reject that schema; release/rollback procedures must preserve this fact rather than suggest an unqualified application-only downgrade. No live deployment was reviewed here.

## Solver research follow-up review

Reviewed the separate `scripts/spike-3d-solver.py`, surface oracle, frozen gather profile and process-group cancellation harness alongside the [solver feasibility report](../research/3d-solver-feasibility.md). Candidate selection remains partial E0 research, not production solver acceptance. Source rest coordinates are retained before placement; the zero-rest sewing springs do not replace cloth rest geometry. Gravity is zero, and finite final positions plus strain/area bounds do not establish convergence or hanging drape.

The surface oracle intentionally excludes topologically adjacent triangles and checks only the final surface. It cannot certify collision thickness, swept motion, adjacent-fold overlap, body penetration or layer ordering. The translated/half-timestep holdout changes two factors simultaneously and is not a full rigid-transform invariance or isolated timestep study.

An independent scale attack found a nonadjacent intersection false negative: a 1 mm triangle crossed by a 20 micrometre vertical triangle was reported separated, while the same coordinates multiplied by 1,000 were reported intersecting. The original implementation reused one absolute tolerance for determinants, lengths, areas and barycentric quantities. The fix separates relative determinant/area checks from geometric distances. Independently reran the exact crossing at scales 0.001, 1 and 1,000, both unchanged and rotated out of plane plus translated: all six cases now detect the crossing. A further far-from-origin coplanar cancellation case was fixed by rebasing the clipping coordinates. Independently ran the final **five oracle unit tests; all passed**.

Independently recomputed the corrected oracle over retained canonical simulation outputs: four baseline fixtures each report zero intersections across 1,750 pairs, refined and translated synthetic gathers each report zero across 7,542 pairs, and the current actual-source gather reports zero across 9,842 pairs. The local oracle findings are closed for this declared discrete-surface scope. This recheck reads saved geometry; it is not an independent rerun of the physics solver and does not accept E0.

Reviewed `docs/research/3d-solver-spike-results.json` and independently verified that its final baseline, frozen holdout and actual-source report script/oracle/profile digests match current files; the actual-source report's shirt/mesher/validator digests also match. The frozen synthetic holdout passes its recorded profile. The actual-source run remains outside that profile and has maximum edge stretch 1.00561, above the synthetic bound of 1.005; it must not be promoted to a profile pass. The earlier failed source mesh remains recorded with 15 surface intersections.

Profile evidence now retains the frozen profile contents and digest plus script/oracle digests, rather than only a mutable profile name. Runtime reporting includes Shapely for the actual-source fixtures. Documentation must distinguish their source meshes from the initial procedural rectangles. License notes correctly distinguish the rejected research-only fork, modern runtime code and bundled binary/asset obligations; this review does not provide redistribution approval.

The lifecycle harness checks only the observed process group. Its single-process observation is not a demonstrated child-process escape test or production lease/install/cancellation race test. Those limitations must remain attached to its termination result.
